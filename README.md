# Shop Sales Dashboard

Excel project analyzing a small shop's sales from July to September 2026 (amounts in SAR). It includes pivot tables, charts, and a KPI dashboard.

## Dataset
- 90 orders, 13 products, 5 categories
- 4 employees, 4 payment methods (Cash, Mada, Credit Card, Apple Pay)

## Workbook Sheets
| Sheet | Content |
|---|---|
| Database | Orders table (`SalesData`) with formulas for Month and Total |
| Data_Source | Copy of the data used as the pivot tables' source |
| Pivot Tables | Quantity per month, sales per category/product, quantity per employee, payment methods |
| Dashboard | KPIs and charts |

## Key Figures
- Total sales: 2,245 SAR
- Orders: 90
- Units sold: 311
- Average order value: 24.94 SAR

## Skills Demonstrated
Pivot tables, pivot charts, Excel formulas (`TEXT`, `RANK`, `SUM`, `COUNTA`), data validation, dashboard design.
